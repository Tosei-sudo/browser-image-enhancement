# 画像ビューア

`browser-image-enhancement/openlayers` を使った画像閲覧サイトです。画像はサーバーに送らず、ブラウザの中で読み込み・補正します。

## できること

- **ローカルファイルを開く**: ヘッダーのフォルダボタン、または表示エリアへのドラッグ＆ドロップ。GeoTIFF と普通の画像（PNG・JPEG・WebP など）のどちらも開けます。複数のファイルをまとめて選べます。オーバービューのない GeoTIFF は、開くときにオーバービュー付きのタイル GeoTIFF に作り直すので、縮小表示でも粗くなりません（約 5,000 万画素 × 3 バンドまで。URL で開く COG はそのまま）
- **Shapefile・GeoJSON（読み取り専用）**: Shapefile は .zip のまま、または .shp・.dbf・.prj（あれば .cpg）を一緒に選びます。属性は属性テーブルに表示され、地図やテーブルで選択できます。属性の文字コードは .cpg に従い、.cpg がなければ UTF-8 か Shift_JIS かを自動で判定します。.prj がない Shapefile は経緯度のときだけ開けます
- **COG を URL で開く**: ヘッダーのリンクボタンから URL を入力。`?url=<COG の URL>` を付けたリンクで開くと、起動時にその COG を開きます（複数指定可）
- **複数の画像を重ねる**: 左の一覧で表示切替・不透明度・重なり順・移動・閉じるを操作できます。一覧で選んだ画像に右上の補正パネルが効き、補正は画像ごとに保持されます
- **補正**: 明るさ・コントラスト・露出・ガンマ・彩度・色温度・レベル・シャープ、表示範囲に合わせた DRA（「範囲を固定」で画像ごとに今のレンジを保ったまま移動・拡大できます）、バンド割当。WebGL2 が使える環境では GPU で補正するので、スライダーにそのまま追従します
- **画像ビューアの表示**: 既定では背景地図はなく、市松模様の背景に画像だけを表示します。開いた画像に合わせて表示範囲を調整します。GeoTIFF 同士は位置情報で重なるので、同じ範囲の画像を重ねて比べられます
- **背景地図**: ヘッダーの「背景地図」で、なし・地理院 標準・地理院 淡色・地理院 写真・OpenStreetMap を切り替えられます（補正はかかりません）
- **サービスのレイヤー**: ヘッダーの「サービスを追加」で URL を入れると、種類（WMS・WMTS・WFS・Esri フィーチャーサービス）を自動で判定してレイヤーの一覧を出します。選んだレイヤーは画像と同じ一覧に入り、表示切替・不透明度・重なり順を操作できます
  - **WMS・WMTS**: 画像と同じように補正パネルで補正できます（GPU で補正するので、サーバーが CORS を許可している必要があります。許可していないサーバーは補正なしで表示します）。WMS は地図をクリックすると、その地点の属性（GetFeatureInfo）を属性テーブルに出します。WMTS はタイル行列セットと画像形式を選べます
  - **WFS・Esri フィーチャーサービス**: 地物をすべて読み込み（1 レイヤー 5 万件まで）、Esri はサービスの描画設定（単一シンボル・個別値・等級区分）で表示します。WFS は 2.0.0・1.1.0・1.0.0 に対応し、GeoJSON を出せるサーバーでは GeoJSON、それ以外は GML で読みます
  - **トークン**: 認証が必要な Esri サービスは、ダイアログの「トークン」に入力します。トークンは保存せず、共有リンクにも含めません
- **属性テーブル**: 地図の下に、選択中の WFS・Esri レイヤーの属性を表示します。「全件」と「選択中のみ」を切り替えられます。行をクリックすると地図で強調表示され、ダブルクリックでその地物へ移動します。見出しで並べ替え、検索欄で絞り込み、「列」で列の表示切替、「CSV 保存」で表示中の行を保存できます。上端をドラッグすると高さを変えられます
  - **複数選択**: Ctrl（Mac は ⌘）+ クリックで追加・解除、Shift + クリックで直前にクリックした行からの範囲を選びます。行頭のチェックボックスでも追加・解除でき、見出しのチェックボックスは表示中の行（検索で絞り込んだ行）をすべて選びます。テーブルにフォーカスがあるとき Ctrl+A で表示中の行をすべて選択、Esc で選択解除です。地図では地物を Ctrl / Shift + クリックで追加、Ctrl（⌘）+ ドラッグで囲んだ範囲の地物を選択に加えます
  - **右クリックメニュー**: 行を右クリックすると「地物にズーム」「行をコピー」（タブ区切りなので表計算ソフトに貼り付けられます）「選択を解除」が出ます。選択中の行を右クリックすると選択中の全件が対象になります。削除できる Esri レイヤーでは「削除…」も出て、確認のあと編集を始めて削除します（「保存」を押すまでサーバーには送られず、「元に戻す」で戻せます）。Delete キーでも同じように削除できます
- **Esri の編集**: 編集できる Esri レイヤーには一覧に ✎（編集）ボタンが出ます。押すと地図の上に編集ツールバーが出て、サービスが許可している操作だけ使えます
  - **追加**: 地図をクリック（ラインとポリゴンは頂点をクリックし、ダブルクリックで終了）。テンプレートの初期値が入り、属性テーブルの「選択中のみ」で属性を入力できます
  - **形状編集**: 頂点や辺をドラッグして形を変えます。選択中の地物はドラッグで移動できます
  - **削除**: 地図か属性テーブルで選んだ地物を削除します
  - **属性**: 編集中は属性テーブルのセルが入力欄になります。コード値ドメインはプルダウン、範囲ドメイン・文字数・型はサーバーの定義に合わせて確認します。OBJECTID や編集者情報など、サーバーが管理する項目は変更できません
  - **保存**: 変更は「保存」を押すまでサーバーに送られません（`applyEdits` でまとめて送信）。保存前は「元に戻す」で 1 つずつ、「破棄」でまとめて取り消せます。未保存のセルは色付き、追加した行は左端に緑の線が付きます。サーバーが受け付けなかった地物は赤く表示し、理由を状態欄に出します。未保存の変更があるままページを閉じようとすると確認が出ます
- **共有リンク**: 追加したサービスのレイヤーと背景地図は URL の `?service=`・`?base=` に入るので、そのリンクを開くと同じ表示になります
- **ポイント**: ヘッダーの「ポイント追加」を押してから、選択中の画像をクリックするとポイントを置けます。名称は左の一覧で編集でき、ポイントはドラッグで動かせます。「GeoJSON 保存」で全ポイントを `points.geojson` に保存します。属性は `image`（画像ファイル名、拡張子なし）と `name`（ポイント名称）です。座標は、GeoTIFF の点が経緯度（WGS 84）、普通の画像の点が画素座標（左上原点、x は右、y は下向き）です。画像を閉じると、その画像のポイントも消えます
- **座標のコピー**: 地図を右クリックすると、その地点の座標をコピーするメニューが出ます。緯度経度（`35.681200, 139.767100` のように緯度が先）、MGRS（`54S UE 88433 49290`）、UTM（`54N 388433 3949290` のように帯番号と南北 N/S）、GeoTIFF が別の座標系ならその座標系の座標、画像の上なら画素座標（左上原点）を並べます。普通の画像の上では画素座標だけです
- **座標へ移動**: ヘッダーの入力欄に座標を入れて Enter で、その地点へ移動して印を付けます。緯度経度（10進・度分秒、`N35.68 E139.77` のような N/S/E/W 付き。記号がないときは緯度が先）、MGRS（精度は任意）、UTM（`54N 388433 3949290`）を読めます
- **情報欄**: 選択中の画像のサイズ・バンド数。GeoTIFF は座標系・解像度・範囲も表示します。サービスのレイヤーは種類・URL・レイヤー名・座標系・地物数・編集できる操作を表示します

サービスは、サーバーが CORS を許可している必要があります（このサイトは中継サーバーを使いません）。今回対応していないものは、WFS-T による WFS の編集、OGC API Features、XYZ タイルのレイヤー追加、Esri の添付ファイル・リレーションシップ・バージョン管理です。

COG は、サーバーが CORS と Range リクエストを許可している必要があります。UTM（WGS 84）の COG は追加設定なしで表示できます。それ以外の座標系は epsg.io から定義を取得します。

## 動かし方

リポジトリのルートで `npm ci` したあと:

```sh
cd usecase/image-viewer
npm run dev        # 開発サーバー
npm run build      # dist/ に静的サイトを出力（相対パスなので任意の場所に置ける）
npm run test:browser
```

ライブラリはワークスペース経由で `packages/browser-image-enhancement/dist` を使います。ライブラリのソースを変えたときは、先に `packages/browser-image-enhancement` で `npm run build` してください。
